{% blocktrans %}N.O.R.A. (Nexus of Ontologies with Reconciliation Assistance) is a web application that helps one map ontologies to a Wikibase instance, such as Wikidata, combining live search on Wikidata with optional semantic search through the Wikidata MCP and optional AI assistance, to suggest matching properties for human review.{% endblocktrans %}

  1. {% translate "Import your ontology" %}

    {% blocktranslate %}Upload your institution's metadata fields.{% endblocktranslate %}

  2. {% translate "Get suggestions" %}

    {% blocktranslate %}NORA suggests matching properties from Wikidata or a Wikibase instance for each field.{% endblocktranslate %}

  3. {% translate "Review each field" %}

    {% blocktranslate %}Accept a suggestion, search for another property, mark the field as having no equivalent, or flag it as a modeling gap to draft a property proposal. AI help is optional and only runs when you ask for it.{% endblocktranslate %}

  4. {% translate "Validate" %}

    {% blocktranslate %}NORA checks datatypes and property constraints before export.{% endblocktranslate %}

  5. {% translate "Export" %}

    {% blocktranslate %}Download a package to reconcile and upload your data with OpenRefine or QuickStatements.{% endblocktranslate %}
